# InFalsusScoreCountdown

把游玩界面左上角的分数换成倒扣分

**English:** Replaces the in-game score with the projected final score.

## 安装

**r2modman / Gale：** 直接安装本包。依赖 `BepInEx-BepInExPack_IL2CPP` 和
`LoaderCompat`

**手动：**

1. `BepInEx/core/InFalsusLoaderCompat.dll`
2. `BepInEx/plugins/InFalsusScoreCountdown/InFalsusScoreCountdown.dll`

## 依赖

- BepInEx **6.0.0-be.788 IL2CPP**
- `LoaderCompat` **1.0.0**
